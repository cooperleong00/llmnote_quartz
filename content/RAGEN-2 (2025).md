# RAGEN-2: Reasoning Collapse in Agentic RL

这篇论文揭示了 [[Agentic RL]] 训练中一个此前被忽视的失效模式：**template collapse**——模型的推理看起来多样（[[Entropy|entropy]] 保持高位），但实际上对不同输入产生几乎相同的推理模板。论文从信息论角度提出了诊断方法（mutual information proxy），从梯度角度解释了成因（SNR 机制），并给出了缓解方案（SNR-Aware Filtering）。

## 核心发现：Template Collapse

> [!intuition] 什么是 Template Collapse？
> 想象一个做数学题的 agent：给它不同的题目，它的 `<think>` 里总是写类似的推理套路——"让我分析一下题目→列出关键信息→尝试求解"——内容看起来多样，但并不是针对具体输入的真正推理。这就是 template collapse。

传统上用 **entropy** 监控 RL 训练的推理稳定性。但 entropy 只衡量**同一输入下**输出的多样性（within-input diversity），无法捕捉**不同输入间**推理是否有区分度。

论文利用信息论的标准恒等式将推理多样性分解为两个正交维度：

$$
H(Z) = I(X;Z) + H(Z \mid X)
$$

- $H(Z \mid X)$：**within-input diversity**（条件熵）——同一输入下推理的多样性。entropy 指标测量的就是这个
- $I(X;Z)$：**input dependence**（互信息）——推理对输入的依赖程度。**这个才是推理质量的关键指标**

Template collapse 就是 $I(X;Z) \to 0$ 而 $H(Z \mid X)$ 保持高位的状态：推理看起来多样，但实际上与输入无关。

> [!warning] 为什么 Entropy 监控会失灵？
> Entropy 只看 $H(Z \mid X)$。模型可以在 entropy 保持高位的同时，$I(X;Z)$ 悄悄下降到接近零。这意味着 entropy 正常 ≠ 推理正常——template collapse 对现有监控指标完全不可见。

论文定义了四种推理状态：

| 状态 | $H(Z \mid X)$ | $I(X;Z)$ | 说明 |
|------|:-:|:-:|------|
| Diverse Reasoning | 高 | 高 | 理想状态 |
| **Template Collapse** | 高 | 低 | 看起来多样但与输入无关 |
| Compressed Reasoning | 低 | 高 | 忠于输入但过于确定性 |
| Low-Entropy Collapse | 低 | 低 | 完全退化 |

## 贡献一：Mutual Information Proxy 诊断方法

直接计算 $I(X;Z)$ 在高维 token 序列上没有闭合形式。论文提出基于 **in-batch cross-scoring** 的近似方法。

核心直觉：如果推理 $Z$ 真的与输入相关，那么 $Z$ 在其真实来源输入 $X_i$ 下的似然应该显著高于在其他输入 $X_j$ 下的似然。如果 $Z$ 是 template，那在任何输入下的似然都差不多。

具体做法是构建评分矩阵 $\mathbf{L}_{i,k,j} = \log p_\theta(Z_{i,k} \mid X_j)$，然后计算：

$$
\text{matched}_{i,k} = \frac{\mathbf{L}_{i,k,i}}{|Z_{i,k}|}, \quad \text{marginal}_{i,k} = \frac{1}{|Z_{i,k}|} \log \frac{1}{P} \sum_j \exp(\mathbf{L}_{i,k,j})
$$

基于这两个量，论文提出了一族 proxy，其中两个主要的：

1. **Retrieval-Acc**（离散、可解释）：推理能否正确"检索"到来源输入？collapse 时退化为 chance level $1/P$
2. **MI-ZScore-EMA**（连续、鲁棒）：matched 与 marginal 的 z-score 归一化差值

> [!math] 实验验证
> MI proxy 与最终任务性能的 Spearman 相关性为 +0.39（Trajectory MI-ZScore），而 entropy 指标为 -0.11 到 -0.14。Entropy 不仅没有预测能力，方向还是反的。

所有 proxy 复用训练 rollout 的 $(X_i, Z_{i,k})$ 对，不需要额外的模型或推理 pass。

## 贡献二：SNR 机制解释 Template Collapse 的成因

> [!intuition] 为什么会发生 Template Collapse？
> RL 训练中，[[Policy Gradient|策略梯度]]由两部分组成：任务梯度（来自 reward 差异）和正则化梯度（来自 [[KL Divergence|KL]] 和 entropy 正则项）。当某个 prompt 的 reward 方差很低时，advantage 趋近于零，任务梯度消失——但正则化梯度与 reward 无关，始终存在。此时模型的更新完全由 input-agnostic 的正则项驱动，推理就会向 template 方向漂移。

形式化地，任务梯度的上界受 reward 方差约束（Cauchy-Schwarz）：

$$
\| g_{\text{task}}(x) \| \leq \sqrt{\text{Var}(R \mid X=x)} \cdot C
$$

低 reward 方差 → 弱 $g_{\text{task}}$ → $g_{\text{reg}}$ 主导 → $I(X;Z) \to 0$。关键是 $H(Z \mid X)$ **不一定下降**，因为 entropy 正则化会维持 within-input 多样性。

论文将总梯度分解为三个成分：

| 成分 | 来源 | 是否 input-dependent | 可控？ |
|------|------|:-:|:-:|
| $g_{\text{signal}}$ | 有意义的 reward 差异 | 是 | 否 |
| $g_{\text{task-noise}}$ | 采样和环境随机性 | 是 | 否 |
| $g_{\text{reg}}$ | KL + entropy 正则项 | **否** | 是 |

SNR 定义为 $\text{SNR}(x) = \|g_{\text{signal}}(x)\| / (\|g_{\text{task-noise}}(x)\| + \|g_{\text{reg}}\|)$。低 SNR 的 prompt 产生的更新主要由 input-agnostic 的正则项驱动。

实验验证（Figure 3）：将 prompt 按 reward 方差分成 6 个 bucket——任务梯度范数随 reward 方差单调递增，正则化梯度范数在所有 bucket 上保持不变。

## 贡献三：SNR-Aware Filtering

基于 SNR 分析，缓解方案很直接：在每次 RL 更新前，**过滤掉低 reward 方差的 prompt**，只在高信噪比的 prompt 上做参数更新。

具体做法是 **Top-$p$ filtering by reward variance**（类似 nucleus sampling 的思路，但排序依据是 reward 方差而非 token 概率）：

1. 对每个 prompt 计算 within-input reward 方差 $\widehat{\text{Var}}(R \mid X)$
2. 按方差降序排列，保留累积方差质量达到 $\rho$ 比例的前 $k^*$ 个 prompt
3. 仅在这些高信号 prompt 上更新参数

> [!comparison] 与其他稳定化方法的区别
> 传统方法（KL 控制、entropy 正则化、reward shaping 等）调节的是正则化强度或 reward 信号。SNR-Aware Filtering 不修改目标函数，而是**选择性地跳过低信号的更新**。这不需要额外的模型或 rollout，可以即插即用到现有 RL pipeline 中。

## 实验结果

论文在 7 个任务上（Sokoban、FrozenLake、MetaMathQA、Countdown、SearchQA、WebShop、DeepCoder）验证了：

**Template collapse 的普遍性**：
- 所有 RL 算法（[[PPO]]、DAPO、[[GRPO]]、Dr. GRPO）都出现 template collapse
- MI proxy 在任务性能下降前就开始下降——是一个**早期预警信号**
- 行为表现为推理长度单调递减（reasoning compression）

**SNR-Aware Filtering 的有效性**：
- 在所有算法变体上平均提升 +0.8% 到 +6.9%
- 跨模型规模（0.5B 到 7B）一致有效
- 跨模型类型（base model、instruct model、不同架构）一致有效
- 跨模态（text input、vision input）一致有效
- Top-$p$ filtering 一致优于 Top-$k$ 和 no-filter baseline

## 局限性

> [!warning] 已知局限
> - SNR 分解假设 task signal 和 regularization noise 能干净地分离，实际中它们可能通过 gradient accumulation 耦合
> - 所有实验都是 single-agent；multi-agent RL 中 template collapse 如何传播未知
> - 有能力的模型可能通过人为抬高 reward variance 来"欺骗"过滤标准
> - 在 sparse 或 noisy reward 环境中，reward variance 作为 SNR proxy 的可靠性下降
> - 过于激进的过滤可能缩小探索覆盖范围，keep rate 需要 per-task 调整
