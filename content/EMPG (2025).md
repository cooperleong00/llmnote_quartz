# EMPG (2025)

> [!paper] 论文信息
> - **标题**：Harnessing Uncertainty: Entropy-Modulated Policy Gradients for Long-Horizon LLM Agents
> - **作者**：Jiawei Wang, Jiacai Liu, Yuqian Fu 等 (ByteDance Seed)
> - **发表**：arXiv 2509.09265, 2025
> - **链接**：https://empgseed-seed.github.io/
> - **核心方法**：[[EMPG]]

## 概述

这篇论文提出 Entropy-Modulated Policy Gradients ([[EMPG]])，一种专门为 long-horizon LLM agent 训练设计的 policy gradient 框架。论文识别并形式化了一个基本问题：[[Policy Gradient|policy gradient]] 的幅度与 [[Entropy|entropy]] 天然耦合，导致 confident correct actions 获得小更新（学习慢），而 uncertain exploratory steps 产生大噪声梯度（不稳定）。

EMPG 通过两个互补机制解决这个问题：
1. **Self-Calibrating Gradient Scaling**：动态调整每步更新的幅度，对抗 entropy-gradient 耦合
2. **Future Clarity Bonus**：提供内在动机，引导 agent 找到更可预测的解决路径

在 WebShop、ALFWorld、Deep Search 三个 long-horizon agent benchmarks 上，EMPG 显著优于 [[GRPO]] 和 [[DAPO]] baseline。

## 核心贡献

### 1. 理论洞察：Gradient Magnitude 与 Entropy 的耦合

> [!math] Proposition 1
>
> 对于 softmax policy $\pi_\theta$，score function 的期望范数是 entropy 的单调函数：
>
> $$
> \mathbb{E}_{a \sim \pi_\theta(\cdot|s)} \left[ \|\nabla_{z_\theta(s)} \log \pi_\theta(a|s)\|^2 \right] = 1 - \exp(-H_2(\pi))
> $$
>
> 其中 $H_2(\pi)$ 是 Rényi-2 entropy。

**含义**：
- 高 entropy（不确定）的 action 自然产生大梯度
- 低 entropy（自信）的 action 产生小梯度

这带来双重挑战：
1. Confident correct steps 应该被强化，但小梯度限制了学习速度
2. Uncertain exploratory steps 的大梯度可能引入噪声，导致训练不稳定

这揭示了需要显式地基于 action 的不确定性重新校准学习信号。

### 2. EMPG 框架

论文提出 [[EMPG]] 方法，包含两个核心机制：

**Self-Calibrating Gradient Scaling $g(H)$**：
- 对 confident steps（低 entropy）：放大更新（$g(H) > 1$）
- 对 uncertain steps（高 entropy）：衰减更新（$g(H) < 1$）
- Self-calibrating 设计：函数在 mini-batch 上的均值归一化为 1，确保调制是重新分配学习信号

**Future Clarity Bonus $f(H)$**：
- 鼓励 agent 选择能导致更可预测的下一步状态的 action
- 对应于局部目标：$\min_{a_t} H(\pi_\theta(s_{t+1}))$
- 提供内在信号用于有目的的探索，引导 agent 远离高 entropy、混乱的轨迹

详细算法说明见 [[EMPG]] 笔记。

### 3. 实验验证

在三个 long-horizon agent benchmarks 上验证 EMPG 的有效性：
- **ALFWorld**：家庭环境中的多步任务
- **WebShop**：电商网站交互任务
- **Deep Search**：复杂搜索任务（包含 ID 和 OOD）

## 实验结果

### 主要性能提升

**ALFWorld**（Qwen2.5-1.5B）：
- GRPO: 65.6% → GRPO+EMPG: 73.7% (+8.1%)
- DAPO: 80.8% → DAPO+EMPG: 88.1% (+7.3%)

**ALFWorld**（Qwen2.5-7B）：
- GRPO: 74.8% → GRPO+EMPG: 78.5% (+3.7%)
- DAPO: 90.0% → DAPO+EMPG: 91.6% (+1.6%)

**WebShop**（Qwen2.5-1.5B）：
- GRPO: 58.2% → GRPO+EMPG: 60.8% (+2.6%)
- DAPO: 73.2% → DAPO+EMPG: 73.8% (+0.6%)

**Deep Search**：
- 在 ID 和 OOD 任务上都显著优于 baseline
- 避免了 baseline 的性能平台期

> [!intuition] 关键发现
>
> EMPG 可以作为 GRPO/DAPO 的增强模块，在不同模型规模和任务上都带来一致的性能提升。

### 训练稳定性

论文通过 KL Loss 的可视化展示了 EMPG 对训练稳定性的改善：
- **Baseline (DAPO)**：在 ~240 steps 后 KL Loss 剧烈波动，出现 policy collapse
- **EMPG**：保持低且稳定的 KL Loss，避免训练发散

这表明 EMPG 的机制（特别是 self-calibrating gradient scaling）有效地正则化了 policy 更新，防止了过于激进的变化。

### Ablation Study

在 Deep Search benchmark 上的 ablation study 揭示了两个组件的互补性：

| 组件 | ID 任务提升 | OOD 任务提升 | 作用 |
|------|-------------|--------------|------|
| Future Clarity Bonus | +2.6% | - | Exploitation 信号 |
| Self-Calibrating Gradient Scaling | - | +3.9% | Regularization 机制 |
| Full EMPG | ✓ | ✓ | 协同效应 |

> [!intuition] 为什么两个组件互补？
>
> - **Future Clarity Bonus**：在训练中强化已知的高质量决策序列 → 掌握 in-domain 分布 → ID 性能提升
> - **Self-Calibrating Gradient Scaling**：教会模型如何在不确定时行为 → 学习鲁棒性 → OOD 泛化提升
>
> EMPG 不是简单地 overfitting，而是学习了一个基本技能：**如何处理不确定性**。

### Step-Level vs Token-Level Entropy

论文分析了 step-level 和 token-level entropy 的动态差异：
- 在 ALFWorld 上分析 9000+ 步骤
- 发现即使是低初始 entropy 的步骤（15%-20% percentile）仍然经历显著的 entropy 变化
- 这与 token-level 的观察不同，验证了 step-centric 方法的必要性

## 与相关工作的关系

### vs GRPO/DAPO

- **[[GRPO]]**：使用 group relative advantage 简化训练，避免 value function
- **[[DAPO]]**：改进 GRPO 的稳定性（Clip-Higher、Dynamic Sampling 等）
- **EMPG**：在 GRPO/DAPO 基础上，根据每步的不确定性动态调制学习信号

EMPG 与 GRPO/DAPO 是互补的，可以作为增强模块使用。

### vs EDGE-GRPO

- **EDGE-GRPO**：在单轮数学推理中，用 entropy 调制梯度，解决 confidence misalignment 问题
- **EMPG**：
  - **动机不同**：针对 multi-step long-horizon 任务的 [[Credit Assignment|credit assignment]] 问题
  - **范围不同**：动态分配整个轨迹的 credit，而非单轮响应
  - **机制不同**：增加 Future Clarity Bonus，引导探索方向

EDGE-GRPO 关注"自信但错误"的响应，EMPG 关注"如何在长轨迹中分配 credit"。

### vs Seed-GRPO

- **Seed-GRPO**：使用 semantic uncertainty 降权高 entropy 响应（sequence-level）
- **EMPG**：step-level 的梯度调制，更细粒度的 credit assignment

### vs Process Reward Models (PRM)

- **PRM**：需要昂贵的人工标注来提供 step-level reward
- **EMPG**：使用内在的不确定性信号（entropy），无需额外标注

PRM 和 EMPG 可以互补：PRM 提供外部监督，EMPG 提供内在信号。

### vs Reinforcement Learning from Internal Feedback

论文将 EMPG 定位在 "从内部反馈学习" 的研究方向中：
- 使用模型自身的不确定性（entropy）作为信号
- 不需要额外的标注或外部模型
- 与使用 self-consistency、Monte Carlo dropout 等方法的工作相关

但 EMPG 的独特之处在于：
- 不是简单地"奖励低 entropy"或"鼓励高 entropy"
- 而是根据 entropy 动态调制学习信号的幅度和方向

## 局限性与未来工作

> [!warning] 局限性
>
> 1. **Entropy 作为不确定性的代理**：
>    - 使用 token-level entropy 的平均值作为步骤级别的不确定性度量
>    - 未来可以探索其他 uncertainty estimators（如 Monte Carlo dropout、ensemble variance）
>
> 2. **Hyperparameter 调优**：
>    - $k$、$k'$、$\zeta$ 需要实验确定
>    - 虽然 self-calibrating 设计减少了超参数，但仍需要调优
>
> 3. **Step 定义的依赖**：
>    - 论文在 "reason-then-act" 步骤级别计算 entropy
>    - 对于不同的 agent 框架，步骤的定义可能不同

**未来方向**：
- 探索其他 uncertainty estimators
- 在更多 agent 任务和框架上验证
- 与 PRM 等外部监督方法结合
- 理论分析 EMPG 的收敛性质
